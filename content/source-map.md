Human and agent authors should read this map, the authoring standard and the relevant canonical architecture before making changes. Revise source meaning before updating an image or presentation. Preserve proposal status, source dates and review limitations. A generated image or successful build does not establish security effectiveness.

The public sources were prepared from the original discussion drafts. Local production notes and operational review receipts were omitted; architecture content and limitations were retained. The repository's publication provenance record identifies the upstream and published source hashes. No global agent configuration is required to read or use these documents.
