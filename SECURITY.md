# Reporting a website security issue

Email [jesse@jessepike.dev](mailto:jesse@jessepike.dev?subject=AI%20Security%20Reference%20Architectures%20website%20security%20report) with the affected URL, observed behavior and a minimal description. Do not post credentials or sensitive exploitation details in a public issue. No response-time commitment is implied.

Questions about the conceptual architectures belong in ordinary feedback or GitHub Issues. This repository is a reference library and static website, not a deployed security control.
